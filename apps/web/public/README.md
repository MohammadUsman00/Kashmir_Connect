# PWA Assets

## Files
- `manifest.json`: install metadata for Kashmir Connect.
- `sw.js`: service worker strategies for API, pages, images, and SOS background sync.
- `offline.html`: fallback page when offline.

## Related Requirements
- Register `sw.js` from the client app.
- Provide icon files at:
  - `/icons/icon-192.png`
  - `/icons/icon-512.png`
